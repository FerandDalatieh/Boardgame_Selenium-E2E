## Description

This project is showcasing an E2E test suite of the [Boardgame app](https://github.com/jaiswaladi246/Boardgame) using Selenium in a TestNG framework written in Java.

## Getting Started

### Dependencies

* Java, Selenium and TestNG

### Executing Tests

1. run the [Boardgame app](https://github.com/jaiswaladi246/Boardgame)
2. execute the tests by running:

```
mvn test
```
